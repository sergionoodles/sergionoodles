### `~❯ cat house-rules.md`

- **Local-first, privacy-first.** Your data stays yours, and nothing leaves the machine unless it has to.
- **Fail closed.** If the sandbox can't start, the app doesn't either.
- **Ship small, ship often.** Then write down what broke.
- **Terminals are a valid aesthetic.** Non-negotiable.
